# 圭表与日晷 · 中国古代天文仪器交互复原

用 Three.js 复原登封告成镇圭表与赤道式日晷，拖动日期/时刻即可看到影长与日影变化，理解古人如何"立竿见影"定节气、定时刻。

在线体验：https://bs2ttfqo7tok.aiworks.site/

## 功能

- **圭表**：八尺表杆 + 石圭刻度。拖动日期，实时计算太阳赤纬、正午太阳高度、影长，并显示二十四节气时间轴与影长年变化曲线。
- **日晷**：赤道式晷面（倾角 55.57°，与赤道面平行），晷针指向天北极（仰角 34.43°），刻度均匀 15°／小时。拖动时刻滑块可看日影方位与长度变化。
- 两个仪器一键切换。

## 科学参数与依据

| 参数 | 取值 | 依据 |
| --- | --- | --- |
| 观测地纬度 φ | 34.43° N | 登封告成镇测景台 |
| 表高 | 8 尺（周尺 0.231 m） | 《周礼》八尺之表 |
| 夏至影长 | 一尺五寸 | 《周礼》"日至之景，尺有五寸" |
| 回归年 | 365.2425 日 | 郭守敬《授时历》 |

计算式：

- 太阳赤纬：δ = −23.44° · cos(360° · (N + 10) / 365)
- 正午太阳高度：H = 90° − |φ − δ|
- 圭表影长：L = 8 / tan H
- 日晷晷面倾角：90° − φ = 55.57°
- 晷针仰角：φ = 34.43°

## 运行

单文件应用，直接用浏览器打开 `index.html` 即可，无需构建。

Three.js r147（UMD，jsDelivr CDN）与 OrbitControls 从 CDN 加载，需联网。

## 说明

日晷演示固定展示北侧晷面；页面时间为真太阳时，与钟表时存在 ±16 分钟的时差（均时差）。
